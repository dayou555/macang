# 飞书导出

飞书 / Lark 在线文档一键导出工具（Chrome / Edge 扩展）。

## 功能

- 飞书文档 → **Markdown / HTML / Word(.doc) / PDF**
- 富文本还原：标题、列表、待办、引用、代码、表格、图片、加粗/斜体/删除线/下划线/颜色、公式（尽力）
- 图片可内嵌（base64，单文件自包含）
- **批量导出**（多链接逐篇）
- **导出历史**
- **转存到飞书**（通过飞书开放平台 OpenAPI 新建文档，需自配应用）
- 侧边栏主界面 + 页面悬浮球 + 设置页

## 安装

解压后在 `chrome://extensions/` 打开「开发者模式」→「加载已解压的扩展程序」→ 选择本文件夹。
详见 **使用说明.md**。

## 说明

- 数据全部在本机处理，不上传第三方服务器；飞书应用凭证只存本机浏览器。
- 需在浏览器中已登录飞书。
- 适用 Chromium 内核浏览器（Manifest V3 + 侧边栏）。

完整使用方法请阅读 **使用说明.md**。

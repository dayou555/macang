飞书配置

飞书应用凭证
用于「转存到飞书」调用开放平台 API · 查看配置文档 ↗
  1. 打开 飞书开放平台 · 开发者后台 → 创建「企业自建应用」
  2. 「凭证与基础信息」复制 App ID 与 App Secret 填到上方
  3. 「权限管理」开通 docx:document 等新版文档读写权限
  4. 「版本管理与发布」创建版本并发布（自建应用需发布后权限才生效）
  5. 回此点「测试连接」验证，通过后即可在弹窗点「转存到飞书」
